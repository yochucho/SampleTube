# SampleTube

SampleTube is a modern Windows desktop downloader powered by yt-dlp. It lets you download videos, audio, and playlists with a clean dark-themed interface.

## Features

- Download YouTube videos, audio, and playlists
- MP3, WAV, and FLAC audio formats
- Playlist downloads organized in History
- Download progress tracking
- Custom download folder
- Automatic filename cleanup
- Download history with metadata
- Optional automatic folder opening after downloads
- Customizable settings
- Colored menu icons and custom application branding

## Download

Download the latest Windows executable from the [Releases](../../releases) page.

## Requirements

The Windows executable requires **FFmpeg** to process and convert audio.

1. Download FFmpeg from [ffmpeg.org](https://ffmpeg.org/download.html).
2. Add FFmpeg to your system PATH, or place `ffmpeg.exe` next to the SampleTube `.exe`.
3. Run SampleTube.
